
# 📄 Dataset Structure Matters

This repository contains the term paper:

**“Dataset Structure Matters: A Dataset-Centric Structural Analysis and Empirical Study of Instruction-Tuning Corpora”**

## 📌 Overview
This work analyzes how the structure of instruction-tuning datasets affects model behavior.  
Three datasets are studied:
- Alpaca  
- Dolly  
- OpenAssistant (OASST1)

## 🔍 Key Contributions
- Dataset-centric analysis (not model-centric)
- Metrics:
  - Length distribution  
  - Lexical diversity (TTR)  
  - Entropy  
  - Structural patterns  
- Empirical evaluation using fine-tuned models

## 📊 Findings
- Dataset structure strongly impacts:
  - Instruction-following quality  
  - Response consistency  
  - Output diversity  
- Dolly shows the most balanced performance
